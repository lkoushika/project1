What is a Protocol?

A protocol is a set of rules that tells computers how to talk to each other. Just like people need to speak the same language to understand each other, computers need to follow the same protocol or they cannot communicate at all!

Protocols decide things like:
1. how data is split up and sent
2. how the data is addressed so it gets to the right place
3. what happens if something gets lost on the way

Common Protocols

Here are some protocols that you use every day without knowing it:

Protocol What it does Port
HTTP Loads web pages 80
HTTPS Loads web pages securely 443

DNS Turns website names into IP addresses 53

TCP vs UDP

These are the two main ways to send data over a network:

  • TCP is careful and reliable. It checks that everything arrived and resends anything that got lost. Used for web pages and email.
  • UDP is fast but does not check anything. Some data might get lost. Used for video calls and online games.

Easy way to remember: TCP is like a phone call where you confirm they heard you, UDP is like shouting across the room.

The OSI Model

The OSI model splits networking into 7 layers. My teacher made us learn them:

  1. Physical (cables and signals)
  2. Data Link (MAC addresses)
  3. Network (IP addresses)
  4. Transport (TCP and UDP)
  5. Session
  6. Presentation
  7. Application (HTTP, DNS, etc.)

Tip: Make up a silly sentence to remember the order!
